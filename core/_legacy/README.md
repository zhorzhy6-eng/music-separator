# Устаревший код (core/_legacy/)

Эти файлы **не используются приложением** и лежат здесь только как история.
Проверено поиском по проекту: ни одного импорта `coresuper_analyzer` или
`piano_reducer` в рабочем коде нет.

## `coresuper_analyzer.py` (663 строки)

Ранняя версия супер-анализа пары «вокал + минус»: пять уровней понимания
(вердикт для ребёнка, взгляд музыканта, звукорежиссёра, ML-инженера, SOTA),
спектральный флатнесс, MFCC, косинусная близость между стемами.

Заменена на `core/super_analyzer.py` (v4.1), где метрики другие:
`phase_smearing`, `spectral_tilt`, `transient_loss`, `bleed_score`,
карта подозрительных секунд. Интерфейс и `core/worker.py` вызывают
именно `core.super_analyzer.super_analyze_pair`.

## `piano_reducer.py` (54 строки)

Сведение многодорожечного MIDI в одну фортепианную партию: низкие ноты
(ниже C3) поднимались на одну октаву, барабаны отбрасывались.

Логика переписана внутри `core/piano_transcriber.py::PianoTranscriber.transcribe`
с другими коэффициентами сдвига (ниже C3 → +2 октавы, C3–B3 → +1 октава)
и с обрезкой pitch по 127. Отдельный класс `PianoReducer` больше не нужен.

## Можно ли удалять

Да. Файлы оставлены только потому, что удаление необратимо без git.
Если история не нужна — папку `core/_legacy/` можно удалить целиком,
на работу приложения это не влияет.
